# salen7in

Landing page for salen7in.de. Static HTML and CSS, no build step, no external requests.

## Adding a demo

Copy one `<article class="demo">` block in `index.html`, newest first. The grid reflows on its own.

## Deploy

The site is served as a static tree by the `salen7in-static` container on the websites host. Deploy and rollback are run by the Webmaster. Release notes live with the Webmaster.
